# OSSR v0.1 protocol

OSSR v0.1 is a testnet-only, single-action sponsorship flow. The transaction origin authorizes the application action; the sponsor supplies the STX fee, sponsor nonce, and sponsor signature.

The protocol is specified by these focused documents:

- [Architecture](ARCHITECTURE.md)
- [Relay API](specs/relay-api.md)
- [Quote format](specs/quote-format.md)
- [sBTC adapter](specs/clarity-adapter.md)
- [sBTC reimbursement](specs/reimbursement.md)
- [Threat model](specs/threat-model.md)

The executable two-party signing demonstration is in [DEMO.md](DEMO.md).
